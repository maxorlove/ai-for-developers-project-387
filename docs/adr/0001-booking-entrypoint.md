# Отдельный адрес для записи на звонок

Главная страница знакомит гостя с сервисом, а кнопка «Записаться на звонок» ведёт на отдельную страницу по адресу /booking/. Так ссылкой на запись можно делиться отдельно, а каталог типов встреч появится по тому же адресу, который сейчас занимает временная страница.
