# Ревью календаря

Сверь весь дифф с согласованным объёмом в исходном обращении, спецификацией и критериями тикетов. Укажи SHA. Проверь предыдущие замечания и результаты CI для этого же SHA. Если результат ещё не готов, укажи это явно.

- Гость выбирает тип встречи и свободное время. Пересечение записей, включая встречи разной длительности, возвращает 409 без создания второй записи. Соседние интервалы могут соприкасаться.
- Владелец видит предстоящие записи. Проверь, какие данные по спецификации должны попасть к гостю, в его список и к владельцу. Текст пользователя отображается безопасно. Старые записи с отсутствующими необязательными полями остаются читаемыми.
- Изменения API проходят от TypeSpec до OpenAPI, SDK и HTTP-проверок. Для изменений интерфейса проверь основной сценарий и отказ в Playwright. При изменении проверок проверь, какую регрессию они ловят.
- Для каждого дефекта приведи путь, строку диффа, воспроизводимое условие и наблюдаемое последствие. Отделяй подтверждённые дефекты от отсутствующих свидетельств. Если дефектов не обнаружено, укажи это. Не выдавай просмотр кода за запуск тестов.
