# Календарь звонков

Сервис, где гость выбирает свободное время для звонка с владельцем календаря.

## Термины

**Гость**:
Человек, который записывается на звонок.

**Владелец календаря**:
Человек, который предлагает время для звонков и видит предстоящие записи.

**Тип встречи**:
Вариант звонка с названием, описанием и фиксированной длительностью.

**Каталог типов встреч**:
Список типов встреч, из которого гость выбирает нужный вариант звонка.

**Свободный слот**:
Доступный интервал времени, достаточный для звонка выбранного типа.

**Запись на звонок**:
Подтверждённое бронирование слота для гостя.
